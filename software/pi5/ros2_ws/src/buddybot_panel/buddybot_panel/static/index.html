BuddyBot Pi5 Local Panel

오프라인에서도 바로 제어 가능한 버디봇 로컬 관제 화면

휴대폰이나 Pi5 연결 모니터에서 접속해서 수동 조작, 추종 전환, 맵 확인, 체크포인트 저장/이동, 텍스트 명령, 브라우저 음성 입력까지 사용할 수 있습니다. 서버컴이 연결되면 Assistant Mode로 확장됩니다.

주행 제어

현재 follow 토글은 로컬 상태와 시연 흐름 기준입니다. 실제 추종 제어는 카메라/비전 노드가 함께 실행되어야 반영됩니다.

미니맵 / 체크포인트

맵과 현재 위치를 불러오는 중입니다.

맵: 준비 중 현재 위치: 없음

체크포인트 저장

맵을 클릭하면 클릭한 좌표가 입력 칸에 들어갑니다. 로컬라이제이션이 켜져 있으면 현재 위치도 함께 표시됩니다.

로컬 명령 / Assistant

Assistant Mode가 켜져 있고 서버가 연결되면 BuddyBot-ai로 요청을 넘기고, 꺼져 있으면 Pi5 내부 로컬 명령 해석만 사용합니다.
