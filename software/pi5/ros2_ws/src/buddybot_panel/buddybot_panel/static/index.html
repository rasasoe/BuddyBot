BuddyBot Mission Console

오프라인 미니맵 생성부터 체크포인트, 사용자 추종까지 한 화면에서 마무리합니다.

미니맵 생성 버튼을 누르면 버디봇이 로봇청소기처럼 천천히 회피 주행하며 방을 훑고, 생성이 끝나면 그 맵 위에 체크포인트를 자유롭게 저장, 삭제, 경로화할 수 있습니다.

빌드: unknown
모드: 독립
서버: 오프라인
운용 준비: 확인 중
추종: off

시스템 상태

로봇 상태와 지금 막히는 항목을 한눈에 정리합니다.

카메라 추종과 명령

카메라 화면을 보면서 추종, 빠른 명령, 수동 화살표 제어를 한 카드에서 바로 쓰도록 정리했습니다. 수동 주행을 누르면 경로와 추종은 자동으로 해제됩니다.

전방 카메라

카메라 미리보기와 수동 조작을 한 위치에 모았습니다.

카메라: 대기 중

/camera/image_raw 가 퍼블리시되면 여기에서 바로 전방 영상을 확인할 수 있습니다.

빠른 명령
추종 시험 준비 상태
실시간 센서 상태를 기다리는 중입니다.
수동 속도 100%
화살표를 누르면 계속 구동되고, 같은 버튼을 다시 누르거나 정지를 누르면 멈춥니다. 전진과 후진은 더 쉽게 출발하도록, 회전은 더 천천히 돌도록 자동 보정합니다.
운용 준비 요약
카메라, LiDAR, 위치, 맵, 사람 검출기 상태 요약이 여기에 표시됩니다.

미니맵, 체크포인트, 경로

생성 중인 미니맵이나 현재 사용 가능한 지도를 불러오는 중입니다.

맵: 대기 중
위치: 없음
미니맵 생성기
LiDAR 기반 로컬 미니맵을 만들고, 완성되면 그 맵에 바로 체크포인트를 저장할 수 있습니다.

새 체크포인트 저장

맵을 클릭하면 x, y가 입력됩니다. SLAM 맵이 아직 없으면 LiDAR 로컬 맵 기준으로 저장합니다.

경로 빌더

아래 체크포인트를 추가한 뒤 바로 실행하거나 저장 경로로 남길 수 있습니다.

저장된 체크포인트

체크포인트 목록 확인 중입니다.

저장된 경로

저장된 경로 확인 중입니다.

음성 명령과 로그

카메라 미리보기는 왼쪽 주행 카드 위로 이동했습니다. 여기서는 음성 입력과 채팅 로그를 집중해서 봅니다.

명령 콘솔
상태, 주방, 정지, 추종, 좌회전, 충전 같은 짧은 명령을 바로 보낼 수 있습니다. 브라우저 음성 입력과 브라우저 TTS도 여기서 계속 쓸 수 있습니다.
