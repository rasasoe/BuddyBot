BuddyBot Mission Console

주행, 체크포인트, 추종 테스트를 한 화면에서 바로 다룹니다.

수동 주행, 체크포인트 저장과 삭제, 즉시 경로 실행, 저장 경로 재생, 카메라 미리보기, LiDAR 지도, 추종 준비 상태를 한 번에 확인할 수 있습니다.

빌드: unknown
모드: standalone
서버: offline
센서융합: 확인 중
추종: off

시스템 상태

Pi, Pico, LiDAR, 카메라, 안전 상태를 확인하고 있습니다.

주행과 추종

수동 주행을 누르면 경로와 추종이 해제됩니다. 추종 준비 상태는 카메라, 사람 검출, LiDAR, 안전 래치를 함께 확인합니다.

추종 시험 준비 상태
실시간 센서 상태를 기다리는 중입니다.
빠른 명령
센서 융합 요약
카메라, LiDAR, 위치, 맵 상태 요약이 여기에 표시됩니다.

맵, 체크포인트, 경로

지도 데이터를 불러오는 중입니다.

맵: 대기 중
위치: 없음
미니맵 생성기
LiDAR 기반 로컬 미니맵을 만들고, 완성되면 그 맵에 바로 체크포인트를 저장할 수 있습니다.

새 체크포인트 저장

맵을 클릭하면 x, y가 입력됩니다. SLAM 맵이 아직 없으면 LiDAR 로컬 맵 기준으로 저장합니다.

경로 빌더

아래 체크포인트를 추가한 뒤 바로 실행하거나 저장 경로로 남길 수 있습니다.

저장된 체크포인트

체크포인트 목록 확인 중입니다.

저장된 경로

저장된 경로 확인 중입니다.

카메라와 콘솔

카메라를 열기 전까지 미리보기는 꺼져 있습니다.

카메라: 대기 중

/camera/image_raw 가 퍼블리시되면 미리보기가 표시됩니다.

명령 콘솔
상태, 주방, 정지, 추종, 좌회전, 충전 같은 짧은 명령을 바로 보낼 수 있습니다. 브라우저 음성 입력과 브라우저 TTS도 여기서 계속 쓸 수 있습니다.
