BuddyBot Mission Console

라이브 LiDAR 미니맵, 체크포인트 이동, 사용자 추종까지 한 화면에서 바로 운용합니다.

미니맵 시작 버튼을 누르면 로봇은 제자리에서 유지되고, 라이브 주행 중 들어오는 LiDAR 스캔으로 로컬 미니맵만 계속 누적합니다. 그 상태에서 바로 체크포인트 저장과 이동을 이어갈 수 있습니다.

빌드: unknown
모드: 독립
서버: 오프라인
운용 준비: 확인 중
추종: off
브라우저 음성: 대기

시스템 상태

로봇 상태와 지금 막히는 항목을 한눈에 정리합니다.

카메라 추종과 명령

카메라 화면을 보면서 추종, 빠른 명령, 수동 화살표 제어를 한 카드에서 바로 쓰도록 정리했습니다. 수동 주행을 누르면 경로와 추종은 자동으로 해제됩니다.

전방 카메라

카메라 미리보기와 수동 조작을 한 위치에 모았습니다.

카메라: 대기 중

/camera/image_raw 가 퍼블리시되면 여기에서 바로 전방 영상을 확인할 수 있습니다.

수동 속도 100%
수동 조작에서는 회피를 끈 상태가 기본이고, 자율주행과 추종에서는 계속 LiDAR 회피를 사용합니다.
화살표를 누르면 계속 구동되고, 같은 버튼을 다시 누르거나 정지를 누르면 멈춥니다. 대각선 이동도 회전 없이 홀로노믹으로 구동되며, 회전은 아래 보조 버튼으로 분리했습니다.
빠른 명령
추종 시험 준비 상태
실시간 센서 상태를 기다리는 중입니다.
운용 준비 요약
카메라, LiDAR, 위치, 맵, 사람 검출기 상태 요약이 여기에 표시됩니다.

미니맵, 체크포인트, 경로

라이브 LiDAR 미니맵이나 현재 사용 가능한 지도를 불러오는 중입니다.

맵: 대기 중
위치: 없음
라이브 미니맵
LiDAR 기반 로컬 미니맵을 라이브로 누적합니다. 체크포인트 이동은 미니맵 시작 없이도 가능하고, 미니맵은 지도 누적용 보조 기능입니다.

체크포인트 이동

체크포인트 이동은 미니맵 시작 없이도 가능합니다. 현재 위치만 잡히면 바로 출발할 수 있습니다.

체크포인트 목록 확인 중입니다.

체크포인트 저장

맵 클릭, 현재 위치, 직접 좌표 중 하나로 저장할 수 있습니다. 현재 위치 저장과 맵 클릭 저장만 있으면 대부분 충분합니다.

경로 빌더

선택한 체크포인트만 쌓아서 실행하거나 저장합니다. 체크포인트 목록에서는 경로 추가 버튼만 남겨 과한 조작을 줄였습니다.

저장된 경로

저장된 경로 확인 중입니다.

음성 명령과 로그

카메라 미리보기는 왼쪽 주행 카드 위로 이동했습니다. 여기서는 음성 입력과 채팅 로그를 집중해서 봅니다.

명령 콘솔
음성모드를 켜면 버디봇 전진, 버디봇 사용자 추종, 버디봇 정지, 버디봇 주방 이동 같은 명령을 바로 실행합니다. 서버컴 연동을 고르면 로봇 명령은 로컬에서 처리하고, 나머지 말은 서버컴으로 보내 자유 대화합니다.
