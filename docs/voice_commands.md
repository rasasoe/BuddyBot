# BuddyBot Voice Commands

이 문서는 BuddyBot 시연/현장 테스트에서 사용할 수 있는 음성 명령어 목록입니다. 코드 기준은 Pi 5의 `buddybot_voice`와 패널 서버의 로컬 명령 파서입니다.

## 기본 규칙

- 발표 모드는 기본적으로 음성 명령이 꺼진 상태로 시작합니다. 패널에서 `음성모드 켜기`를 눌러야 합니다.
- 권장 STT 모드는 `BUDDYBOT_STT_MODE=legacy_google`입니다.
- Pi local Whisper와 server Whisper는 테스트 모드입니다. Pi 5 발표 모드에서는 지연이 커질 수 있습니다.
- 로봇 이동 명령은 Pi 5가 로컬에서 먼저 처리합니다.
- 서버 AI는 날씨, 시간, 설명, 일반 대화, TTS를 담당합니다.
- LLM 응답은 모터 명령으로 직접 연결하지 않습니다.
- 서버 연동 모드에서도 마이크 대화는 `버디봇` 호출어가 있어야 서버로 전달됩니다.

## 추천 시연 문장

```text
버디봇
버디봇 앞으로
멈춰
버디봇 일로와
버디봇 따라와
멈춰
버디봇 오늘 날씨 알려줘
버디봇 미니맵 설명해줘
```

`전진`과 `정지`는 짧은 2음절이라 STT가 헷갈릴 수 있습니다. 시연에서는 `앞으로`와 `멈춰`를 기본 조합으로 쓰는 것이 가장 안정적입니다.

## 호출어

아래 호출어 뒤에 바로 명령을 붙여 말할 수 있습니다.

```text
버디봇
버디봇아
버디 봇
버디 봇아
바디봇
바디 봇
버디보
버디 보
버디보트
버디
buddybot
buddy bot
buddy
```

호출어만 말하면 `네`라고 응답하고 약 10초 동안 다음 명령을 기다립니다.

```text
사용자: 버디봇
버디봇: 네
사용자: 앞으로
```

## 긴급 정지

아래 명령은 호출어 없이도 최우선 처리합니다. 실제 운용에서는 `멈춰`를 가장 권장합니다.

```text
멈춰
멈춰줘
멈춰 줘
멈추세요
멈춰주세요
멈추어
멈춰라
멈춤
멈추
스톱
스탑
중지
취소
그만
그만해
세워
세워줘
정지
정지해
stop
halt
brake
cancel
```

정지 명령 처리 순서:

1. 수동 이동 명령 해제
2. 사용자 추종 해제
3. 체크포인트/내비게이션 취소
4. zero velocity 여러 번 발행
5. 로컬 음성으로 정지 응답

## 이동 명령

### 계속 전진

정지 명령을 받을 때까지 계속 전진합니다. `BUDDYBOT_VOICE_CONTINUOUS_MAX_SEC`를 설정하면 안전 timeout을 둘 수 있습니다.

```text
버디봇 앞으로
버디봇 앞으로 가
버디봇 전진
버디봇 전진해
버디봇 가자
버디봇 직진
forward
go ahead
```

STT 보정 후보:

```text
정진
전지
전짐
전 좀
```

강조형 전진:

```text
버디봇 계속 전진
버디봇 계속 앞으로
버디봇 앞으로 계속
버디봇 앞으로 계속 가
버디봇 주행 시작
버디봇 계속 가
버디봇 쭉 가
버디봇 쭉 전진
버디봇 계속 직진
```

아래 명령은 짧은 전진이 아니라 사용자 추종을 시작합니다. 시연에서는 `버디봇 일로와`, `버디봇 이리와`, `버디봇 나 따라와`를 추종 시작 명령으로 사용할 수 있습니다.

```text
버디봇 일루와

버디봇 이루와
버디봇 이루 와
버디봇 이리와
버디봇 이리 와
버디봇 이리와줘
버디봇 이리 와줘
버디봇 여기로와
버디봇 여기로 와
버디봇 여기로와줘
버디봇 이쪽으로와
버디봇 이쪽으로 와
버디봇 내쪽으로와
버디봇 내 쪽으로 와

버디봇 앞으로 와
버디봇 가까이 와
```


## 서버 AI 질문

서버 연동 모드에서 사용할 수 있습니다. 로봇 명령이 아닌 문장은 BuddyBot-ai `/chat`으로 전달되고, 답변은 서버 Edge TTS를 우선 사용합니다.

```text
버디봇 오늘 날씨 알려줘
버디봇 서울 날씨 알려줘
버디봇 지금 몇 시야
버디봇 너는 누구야
버디봇 네 기능 설명해줘
버디봇 사용자 추종 설명해줘
버디봇 미니맵 설명해줘
버디봇 안전 구조 설명해줘
버디봇 갈비찜 레시피 알려줘
버디봇 코딩이 뭐야
버디봇 메모해줘 내일 배터리 충전
```

서버가 꺼져 있어도 로컬 이동, 정지, 추종, 체크포인트 명령은 계속 사용할 수 있어야 합니다.

## 음성 출력 정책

- 긴급 정지는 TTS보다 먼저 실행합니다.
- 짧은 시스템 응답은 Pi 로컬 사전 음성 또는 로컬 TTS fallback을 사용합니다.
- 일반 AI 답변은 서버 Edge TTS를 우선 사용합니다.
- 서버 TTS가 실패하면 Pi 로컬 fallback 응답을 사용합니다.

## 디버깅

Pi에서 음성 로그:

```bash
tail -n 160 ~/BuddyBot/software/pi5/ros2_ws/log/mapping_panel/voice.log
```

확인할 항목:

```text
stt_mode
stt_backend_used
stt_elapsed_sec
raw_stt_text
normalized_text
wake_detected
wake_matched_alias
command_text
local_intent
```

음성 명령이 아예 안 들리면 먼저 패널에서 `음성모드 켜기`가 눌렸는지 확인합니다.
