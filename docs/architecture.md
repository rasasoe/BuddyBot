# BuddyBot 아키텍처

## 개요

BuddyBot은 라즈베리 파이 5 + 라즈베리 파이 피코 기반 옴니휠 홈 어시스턴트 로봇입니다.

## 시스템 아키텍처

### 하드웨어 구성 요소
- **라즈베리 파이 5**: 뇌 (ROS 2, 비전, 네비게이션, 음성)
- **라즈베리 파이 피코**: 척수 (모터 제어, 안전)
- **LiDAR**: 매핑 및 글로벌 네비게이션
- **카메라**: 사람 추적 및 로컬 안전
- **옴니휠**: 3륜 홀로노믹 드라이브

### 소프트웨어 아키텍처

#### ROS 2 패키지 (Pi 5)
- **buddybot_msgs**: 사용자 정의 메시지 정의
- **buddybot_base**: 핵심 기능 (통신, 뮤텍스, 모드)
- **buddybot_vision**: 컴퓨터 비전 작업
- **buddybot_nav**: 네비게이션 스택
- **buddybot_voice**: 음성 인터페이스
- **buddybot_system**: 모니터링 및 진단
- **buddybot_bringup**: 런치 구성

#### 피코 펌웨어
- PID를 사용한 모터 제어
- 엔코더 피드백
- 워치독 안전
- 시리얼 통신

## 안전 아키텍처

1. **워치독**: 피코가 Pi 5 실패 시 모터 정지
2. **명령 뮤텍스**: 중앙 집중식 명령 중재
3. **비상 정지**: 다중 트리거 메커니즘
4. **광학 플로우 TTC**: 비전 기반 충돌 회피
